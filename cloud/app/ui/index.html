Kéo thả file dữ liệu vào đây JSON · JSONL · CSV · MD · TXT — mỗi mục/đoạn sẽ thành 1 memory (≤ 1000 mục/file)
Định dạng file?
JSON / JSONL: mảng object hoặc mỗi dòng một object
[{"title":"...","content":"...","type":"lesson","importance":0.8}]

CSV: cần cột title,content; tuỳ chọn type,importance,confidence

MD: mỗi heading (## Tựa đề) thành 1 memory
TXT: mỗi đoạn cách nhau bằng dòng trống thành 1 memory
Mục đích: nạp kiến thức/nhiệm vụ hàng loạt để model (agent, deep-learning pipeline) retrieve và tự thực thi sau này. Mọi nội dung vẫn qua redact secrets + dedupe.
